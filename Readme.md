# Day 10: Hyper Starburst Burst Network 🌌⚡

A high-density 60 FPS particle burst network animation built entirely in pure Python using `turtle` and `math` mechanics. Features dual-layer counter-rotating radial expansion beams, dynamic 3D depth pulsing, and a clean prime neon palette.

## Key Features
- **Pure Python Mechanics**: No external game engines or video editing tools used.
- **Dynamic Kinetic Modulators**: Synchronized counter-rotating speed vectors with parametric sine-wave pulsation.
- **6-Prime Neon Palette**: Uses high-contrast Electric Cyan, Laser Magenta, Neon Green, Golden Yellow, Deep Violet, and White on an AMOLED pitch-black background.
- **3D Depth Scaling**: Node dot sizes and line thickness scale dynamically relative to distance and frame timing.

## Tech Stack
- **Language**: Python 3.x
- **Libraries**: `turtle`, `math`, `colorsys`
